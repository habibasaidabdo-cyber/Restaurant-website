## 🍕 About

This is a fully responsive restaurant website designed to provide customers with an engaging online experience. Browse our menu, read reviews, and make reservations all in one place.

## ✨ Features

- **Homepage**: Welcome page with restaurant highlights
- **Menu Categories**: 
  - Appetizers
  - Soups
  - Main Dishes
  - Baked Items
  - Sweets & Desserts
  - Drinks
- **Reservation System**: Easy online table booking
- **Customer Reviews**: Read what our customers say about us
- **Responsive Design**: Works seamlessly on all devices

## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, or Edge)
- No additional software or dependencies required!

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/habibasaidabdo-cyber/Restaurant-website.git
   ```

2. **Navigate to the project folder**:
   ```bash
   cd restaurant
   ```

3. **Open the website**:
   - Simply open `index.html` in your web browser
   - Or use a local development server (optional)

## How to Run

### Method 1: Direct Browser Opening (Easiest)

1. Navigate to the project folder
2. Double-click on `index.html`
3. The website will open in your default browser

### Method 2: Using a Local Server (Optional)

If you have Python installed, run:

```bash
python -m http.server 8000
```

Then open your browser and go to `http://localhost:8000`
